## <img src="https://user-images.githubusercontent.com/74038190/216122041-518ac897-8d92-4c6b-9b3f-ca01dcaf38ee.png" width="26" /> &nbsp; About

I build the layer between raw data and things that make decisions.

Day to day I'm a **Data Engineer at Navikenz**, working in Databricks and Delta Lake —
I shipped a data ingestion framework that standardised ETL across multiple sources, a
deduplication engine using ML similarity and hashing, and the QA for a client-facing
**agentic AI ingestion pipeline** running under production load. Most recently I led
**Navisphere**, migrating Databricks analytics onto a React self-serve interface so
non-technical stakeholders stopped queueing behind an analyst for ad-hoc queries.

Outside the warehouse, the interesting problems are **agentic and applied ML**. I
trained a PPO scheduling agent for 500k timesteps that hit 100% scheduling success at
roughly 4× the untrained baseline, and a 27-class CNN doing real-time ASL fingerspelling
at 30+ FPS on CPU alone.

I'm **full-stack when the work needs shipping** — FastAPI microservices, Next.js
dashboards, and the wiring between them. A model that nobody can reach isn't finished.

<summary><b>&nbsp;What's actually inside the two flagships</b></summary>
<br/>

**NaviMed Scheduler** — `Python` `FastAPI` `PPO / Stable-Baselines3` `Next.js` `ARIMA`

A reinforcement-learning clinic scheduler. The PPO agent trains for 500k timesteps in a
simulated 3-doctor, 32-slot/day environment with emergencies, priority tiers and no-show
risk, reaching **100% scheduling success at 37.35 average reward — roughly 4× the
untrained baseline**. Around it sit FastAPI microservices for RL inference, no-show risk
scoring over a 110k-appointment dataset, and ARIMA demand forecasting, all surfaced
through a Next.js admin dashboard with an LLM chatbot for booking and rescheduling.

**SignaText** — `TensorFlow` `Keras` `OpenCV` `MediaPipe` `CNN` `NLP`

Real-time ASL fingerspelling to text. A 27-class, 843K-parameter CNN with a two-stage
recognition pipeline — a main classifier plus dedicated letter-group classifiers for
visually similar pairs — gated on 50-frame stability. Runs at **30+ FPS on CPU**, with
NLP post-processing assembling letters into coherent words. Team lead.
